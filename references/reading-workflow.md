# EPUB 精修流程

1. **确认底本。** 核对书名、作者、译者或修订版。遇到 ZIP 时查看成员及文件实际格式。已有文字层的 EPUB 直接读取正文，扫描件才考虑 OCR。发现错字时回查原文件同一位置，确认问题来自底本还是本次转换。
2. **检查阅读杂音。** 按实际阅读顺序扫描正文、章末和附录。关注方块占位、字母混入汉字、孤立数字、推广段落、空的作者留言标题和空白排版块。结合上下文区分注释编号、外文、分隔符和真实作者留言。清理空标题前，检查同版同章的可读来源是否有留言。保留有内容的注释、留言和后记。
3. **按证据修字。** 优先对照同一译本或修订版，记录章节、原字、改字及依据。可以用其他版本辅助辨认短词，但要核对上下文。存疑处保留原文并简要记录。抽查与逐段核对分别报告。
4. **整理阅读排版。** 用户指定样板书时，读取正文的边距、行距、段落和章标题样式，再把需要的规则应用到目标书的正文。没有样板时可选 `cn-novel`，先试一章，再应用到全书的正文文件。检查原有内联样式、强制页边距、章首空白和旧注释颜色是否仍影响阅读。对已确认无内容的占位块、重复注释符号按书处理，保留跳转目标。已有章标题就整理样式；需要补章号时先核对目录与阅读顺序。
5. **处理封面和页码。** 优先使用指定图片。联网寻找时按作者、译者和版本核对，挑清晰图并记录来源，显示时保持比例。保留现有目录及可用页码，需要新增时按阅读器和传书方式处理。估算页码用于记录阅读进度。
6. **复核后交付。** 将纯排版操作前后的正文逐段对比，确保文字和顺序一致。逐项检查目录、脚注和页码跳转，抽看封面、章首、章末及带注释的页面。报告实际完成的检查和存疑项，按用户指定位置保存。Kindle 邮件转换后的表现由设备实测确认。

`cn-novel` 为可调字号的 EPUB 3 正文提供 5% 左右边距、1.8 倍行距、两字缩进、半字高段间距、居中的一级标题，以及跟随主题颜色的语义注释样式。命令按 EPUB 包内的文件路径选择正文。对旧版 Calibre 等来源的专用注释类和空白块，先检查实际用途，再按书调整。命令及示例见 [命令参考](commands.md)。
